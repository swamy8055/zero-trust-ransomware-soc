# Recovery Trust Chain

1. Identify the compromised region.
2. Stop suspicious replication.
3. Verify backup integrity.
4. Restore the backup in a clean environment.
5. Validate application files.
6. Validate database integrity.
7. Validate identity configuration.
8. Rotate compromised credentials.
9. Enable monitoring.
10. Validate Region-B.
11. Approve controlled failover.
12. Continue post-recovery monitoring.
